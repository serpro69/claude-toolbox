# Recognizing archived catalog entries

The planned manual update to catalog.md will let contributors identify archived
entries without opening them. An archived entry will display `Archived` beside
its existing linked title. Its title and link destination will stay the same;
active entries will receive no label.

Filtering and automatic archival are outside this change. Catalog maintainers
will choose a color after checking contrast; the text label does not depend on
that decision. This documentation-only change claims no implementation or runtime
validation. See the [accepted contract](../feature/requirements.md).
