# Note archive

A local note collection is maintained by its owner. Items have a stable ID, title, body, and an archived flag. Existing listing includes active and archived items, marked distinctly. Existing editing preserves IDs and links. No runtime source or selected language exists in this planning workspace.

The requested archive command marks one selected item as archived and keeps its content and links. It must not delete an item or hide it from the ordinary list. Repeating the command should leave the same archived state. A missing ID should be reported without changing any item. Bulk archival, restore, and synchronization are outside this increment. No new dependencies or network access are needed.
