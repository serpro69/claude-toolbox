1. Large CSV exports currently run within the request, keeping users waiting. The feature would let them continue working and download the export when ready.

2. A user starts an export of selected rows, continues working, and later downloads a CSV containing those originally selected rows in their original column order.

3. Continuing work and downloading when ready are accepted. The CSV contents and column order are acceptance criteria. A queue plus a token is proposed; the queue is not signed off. Nothing is implemented yet.

4. Notifications are out of scope.

5. Mira must choose the download expiry before implementation; no value is agreed. The mechanism must be chosen afterward, but its decision owner is unspecified.
