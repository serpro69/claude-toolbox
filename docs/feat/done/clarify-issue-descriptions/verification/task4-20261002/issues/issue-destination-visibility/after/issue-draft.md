# Download selected rows

Partners need to keep working while a CSV export is prepared. The proposed feature
lets a partner start an export, continue working, then download the selected rows
in their original column order. That row/column preservation is the agreed
criterion; background export is not implemented. Notifications are excluded.
Jo must decide the rollout audience before implementation; no audience is chosen.

See [requirements](https://partners.example.invalid/requirements),
[Task 8](shared-tasks.md), and the [public format](https://public.example.invalid/csv-format).
