1. Large CSV exports currently run within the request, making users wait. The feature would let them continue working and download the export when ready.

2. A user starts an export of selected rows, keeps working, then downloads a CSV containing the originally selected rows in their original column order.

3. Continuing work and downloading later are accepted requirements. A queue plus token is a proposed mechanism, without sign-off. Nothing is implemented yet.

4. Notifications are out of scope.

5. Mira must decide download expiry before implementation. The mechanism will be chosen afterward; the artifact does not identify who owns that choice.
