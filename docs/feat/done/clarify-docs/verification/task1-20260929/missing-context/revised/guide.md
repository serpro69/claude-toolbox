# Export storage

The export feature is intended to give service owners a downloadable record of
completed orders. Under the accepted contract, each export request creates one CSV
and returns its download link. Scheduled exports are outside this increment.

These requirements describe the accepted contract, not verified running behavior:
no implementation was supplied for this guide.

Cleanup timing remains unresolved because `retention.md` is unavailable. No
retention duration is established by the supplied requirements. The data steward
must supply the retention decision before cleanup behavior can be documented.
