# Accepted export intent

Users need to keep working while an export is prepared and download it when ready.
Current exports complete synchronously. This feature is not implemented.
Existing acceptance criterion: the downloaded CSV contains the originally selected
rows in their original column order. This is the only agreed acceptance criterion.
Notifications are excluded. Download expiry is undecided: Mira must decide it
before implementation; there is no agreed duration, performance target or row cap.
Mechanism selection follows that decision.
