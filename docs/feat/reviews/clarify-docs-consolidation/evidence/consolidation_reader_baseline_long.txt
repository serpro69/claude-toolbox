2. Write `"reserveRule": null` to restore inheritance. The server removes the stored key; storing null is invalid. A subsequent public read shows `reserveRule: null`, `effectiveReserveRule` equal to the current warehouse default, and `ruleSource: "warehouse"`. Writing `{"kind":"none"}` instead creates an explicit SKU override with no minimum restriction, which persists across warehouse-default changes.  
   **Pointers:** “Rules and editor operations”; “Public data and implementation notes.”

For an otherwise valid request containing a missing SKU, return HTTP 404 `SKU_NOT_FOUND`, with only the missing submitted IDs in `data.affectedSkus`. No selected row changes; preserve selection and unsaved input.  
   **Pointer:** “Bulk request and examples,” especially `#bulk-safety`.

4. Each selection requests one unit. A would fall from 8 to 7, below the inherited minimum of 10, so preview rejects A with `LOW_STOCK`. B’s explicit none rule allows it while enabled and stocked. Preview returns HTTP 200 `PREVIEW_EVALUATED`, with B in `data.allowed` and A in `data.rejected`, without changing stock. Confirming both returns HTTP 409 `RESERVATION_REJECTED` with the evaluated allowed/rejected results; neither SKU loses stock. Keep both selected and display rejection reasons until the user removes entries. Preview cannot be relied on after stock or rule changes: it reserves nothing, locks nothing, and confirmation must reload and recheck current data.  
   **Pointers:** Introduction; “Previewing selected SKUs”; “Confirming a reservation.”

5. The proxy must preserve the original HTTP status and complete JSON envelope (`code`, `message`, optional `data`). The client must use status and outcome to distinguish success from failure; structured `data` can appear in errors, and older errors may omit it. Neither data presence nor an empty array proves success. A failed preview leaves availability unknown and must not become an apparently successful empty result. A successful HTTP 200 `PREVIEW_EVALUATED` with an empty `allowed` array is a completed evaluation that currently allows none. Preserve input and selections on failures.  
   **Pointers:** “Handling responses”; “Previewing selected SKUs.”
