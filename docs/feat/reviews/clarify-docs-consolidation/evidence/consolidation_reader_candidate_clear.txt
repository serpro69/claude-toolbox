1. **Why:** Let restaurant owners set a preparation default with item overrides, while preserving the resolved preparation time on existing orders. (§ “Preparation defaults,” paragraph 1)
2. **Representative case:** With a 15-minute default, missing or null `prep_minutes` inherits 15; explicit zero stays 0. Changing the default to 20 changes subsequent inherited lookups to 20, while zero stays 0 and an earlier order keeps 15. (§ “Preparation defaults,” paragraph 2)
3. **Current increment:** Adds current-value lookup through `effective_minutes` and an order snapshot copied by `create_order`. The storage field is `prep_minutes`. (§ “Preparation defaults,” paragraphs 1 and 3)
4. **Outside scope:** Scheduling. (§ “Preparation defaults,” paragraph 3)
5. **Open decision:** The product owner must decide inheritance badges for the menu editor. (§ “Preparation defaults,” paragraph 3)
