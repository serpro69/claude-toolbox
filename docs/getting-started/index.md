# Getting started

Agentstakk is the new name for claude-toolbox. Starting with v0.26.0, one `kk` installation provides the launchers, skills and guards across your projects. Choose the path that matches what you have today.

| Your setup | Where to start |
| --- | --- |
| New installation or an ordinary project | [Install kk on your machine](install.md), then start `kk claude` or `kk codex` in the project. |
| A claude-toolbox repository with `.github/template-state.json` | [Migrate the template](../user-guide/template-sync.md). Each user installs kk once. The team reviews one migration diff per repository. |
| The plugin `kk@claude-toolbox` installed directly | [Switch the Git marketplace](plugin-only.md#switch-an-existing-git-marketplace-installation) to keep using your provider’s CLI, or [install kk](install.md) to adopt the managed settings and launchers. |
| Your own CLI configuration and you want only the plugins | [Install from the public marketplace](plugin-only.md). |
| A working installation | [Try your first design and review](quickstart.md). |
