# Getting started

**[Install kk on your machine](template-setup.md)** to use the workflow skills, guards and launcher settings across repositories. From a toolbox checkout, run `./install.sh --local .`, put `~/.local/bin` on your `PATH`, then run `kk status`. Start a session in your project with `kk claude` or `kk codex`.

| If you already have… | Next step |
| --- | --- |
| An ordinary repository | Start the launcher in its working tree. [Using an existing project](adopting.md) |
| A repository with `.github/template-state.json` | Verify the machine guards and preview what your team would lose or keep. [Migrate the template](../user-guide/template-sync.md) |
| Your own CLI configuration and a preference for vendor-managed plugins | Install the workflow plugin directly from the Git marketplace. [Plugin-only setup](plugin-only.md) |
| A working installation | Run your first design and review. [Try it](quickstart.md) |
