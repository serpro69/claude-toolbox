# Accepted archive-label contract

The guide explains a planned manual edit to catalog.md so contributors can identify
archived entries without opening them. Archived entries will display `Archived`
beside their existing linked title. Titles and destinations remain unchanged;
active entries receive no label. Filtering and automatic archival are excluded.

Catalog maintainers own the future color choice and must check contrast first.
Text labels do not depend on that choice. No implementation or runtime validation
is claimed by this documentation-only change.
