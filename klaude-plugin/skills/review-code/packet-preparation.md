# Instruction preparation

Preparation has one outcome: all applicable instruction bytes have returned
before subject investigation. The helper packages existing files and checks
membership; it neither detects profiles nor grants permission to investigate.
Read-only isolated agents continue to use the direct source paths supplied by
their parent.

1. Execute the helper path supplied by SKILL.md with argument `bootstrap`.
   Read **every** returned part, in order, through its `END PACKET PART` marker.
   Request the remaining lines if a Read is truncated. These parts contain the
   full process, shared protocols, common method and every Known-profile
   detection file. Source headers give original paths for relative links.
2. Resolve scope from filenames/metadata under the loaded process. Apply the
   loaded detection rules, preserving each match/non-match/ENOENT outcome.
   For active profiles, run `profiles --profile NAME` (repeat `--profile` as
   needed), then Read all returned parts to load their indexes. Resolve their
   conditionals using only the allowed bounded predicate inspection.
3. Run `checklists` with each active `--profile NAME`, a `--load
   NAME/checklist.md` for every selected entry, and a `--skip
   'NAME/checklist.md=concrete unmatched predicate'` for each unselected
   conditional. Select undecidable conditionals conservatively. The helper
   rejects incomplete index coverage, unknown entries and skipped always-load
   files. It does not verify the truth of your predicate decisions.
4. Read every checklist-packet part fully. Emit one compact preparation
   checkpoint: selected diff, detection outcomes, selected checklist sources,
   and completed packet parts. Only completed returned text counts. Then enter
   the process's investigation phase.

For no active profiles, record that result and no selected checklists; the
common instructions still apply. Packet creation and hashes establish packaging,
not reading or behavioral compliance. Use tool results to establish ordering.
Keep packet files available through the review/evidence capture; they contain
no reviewed source and live in newly allocated temporary directories.

**Direct-read fallback:** if Python/helper execution is unavailable or the
helper cannot package an instruction/index faithfully, retain that limitation and read the
process and its shared/common instructions, every Known-profile detection file,
active indexes and every selected checklist directly. Use the same scope,
predicate and completion rules. A valid complete packet Read supplies the
original source contents for those reads; do not reread identical files merely
because they arrived together. Missing required instructions still block
investigation, with only the shared detection procedure's defined fallbacks.
